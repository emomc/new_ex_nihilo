Generated from NovaMachina-Mods/ExNihiloSequentia branch 1.21 on 2026-05-21.

This port registers 119 item IDs and 53 block IDs under new_ex_nihilo. The original repository states that source code is CC BY-NC-SA 4.0 and artwork is All rights reserved, so this project does not copy original artwork. Generated models currently reference vanilla placeholder textures.

Behavior-heavy objects such as sieves, barrels, crucibles, dolls, fluids, recipes, and block entities are represented as simple registered items/blocks in this pass.
